# Skill 管理与安装体验改进

本文汇总 v0.10.0 对 My Skills、安装选择、异常提示和详情页面的用户体验修复。

相关 PR：[#124](https://github.com/qufei1993/skills-hub/pull/124)、[#132](https://github.com/qufei1993/skills-hub/pull/132)、[#133](https://github.com/qufei1993/skills-hub/pull/133)、[#136](https://github.com/qufei1993/skills-hub/pull/136)、[#138](https://github.com/qufei1993/skills-hub/pull/138)。

## My Skills 顶部与筛选

- 使用“全部、全局、项目”范围按钮和数量替代四张大型统计卡片，并移除重复的范围下拉框。
- 范围数量基于完整托管列表；标签和“未打标签”数量基于当前范围及搜索结果，但不受已选标签反向限制。
- 零数量的未选标签不可选，已选标签仍可取消。
- 存在同步异常时显示紧凑的异常 Skill 数量和处理入口；无异常时不占用页面空间。
- 有筛选时显示结果数量和清除入口，并区分“Skill 库为空”和“筛选无匹配”。
- 从标签管理打开指定标签时，将范围恢复为全部并清空旧搜索条件。

## 可见选择与批量操作

筛选只隐藏条目，不丢弃用户原有勾选。批量数量、按钮状态、确认内容和实际操作只使用当前可见且已选中的 Skill，避免对隐藏条目执行意外操作。清除筛选后，之前的勾选状态仍会恢复显示。

## 筛选后的安装范围

多 Skill Git 仓库和本地目录默认可以勾选多个候选。此前搜索后虽然界面只显示匹配项，安装处理仍可能提交被隐藏的选中项。

修复后：

- Git 和本地导入使用同一份“当前可见且已选”列表计算数量和提交子路径。
- 本地导入继续排除缺少有效 `SKILL.md` 的候选。
- 搜索不会清除隐藏候选的勾选状态；清空搜索后恢复展示。
- 无匹配项、当前可见项均未选中或来源为空时，主操作按钮保持禁用。

## 紧凑的 Skill 异常提示

Skill 卡片仅在需要处理时，于复制按钮旁显示警告图标。点击后可在紧凑浮层中查看已有的安全原因及恢复建议；支持关闭按钮、Esc 和点击外部关闭。正常卡片不显示警告，异常判断和详情页提示逻辑保持不变。

来源更新、设备同步和工具分发状态的详细边界见[设备同步可靠性与安全修复](device-sync-reliability.md)。

## 来源缺失时的详情页面

本地原始来源不存在时，Skill 仍会显示来源异常，但提示条只占自身内容高度，不再把标题、文件树和文件内容挤出可视区域。详情页继续读取中央仓库中的托管副本，因此用户仍可检查已有文件；来源异常和更新保护不会被隐藏或清除。

## 设计边界

- 不改变 Skill 卡片的健康状态判断。
- 不因搜索而修改持久化选择。
- 不改变同步、安装或数据库业务模型，只让提交范围与界面展示一致。
- 使用现有主题变量、键盘焦点和响应式规则，支持英文、简体中文和韩文。

## 验证范围

前端回归覆盖范围和标签计数、隐藏批量选择、筛选无结果、清除筛选、标签管理跳转、Git 与本地候选搜索、无效候选、加载状态、警告浮层关闭方式，以及来源缺失时详情布局。上述关键用例均在旧行为下复现失败，并在修复后通过。
