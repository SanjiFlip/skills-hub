# 托盘图标与关闭到托盘

## 问题

关闭窗口会直接退出应用：`lib.rs` 的窗口事件处理在收到 `CloseRequested` 时调用 `app_handle().exit(0)`。这意味着只要用户关掉窗口，计划任务更新与设备同步都会随之中断；如果用户本意只是把窗口收起来，就必须重新启动应用。

## 修复

- 启用 Tauri 的 `tray-icon` feature，并在 `setup` 中创建托盘图标：菜单包含「显示主窗口」和「退出 Skills Hub」，左键单击图标直接恢复窗口。
- 关闭窗口改为隐藏：`CloseRequested` 事件调用 `api.prevent_close()` 并 `window.hide()`，应用继续在通知区域运行。真正的退出由托盘菜单触发。
- 安全回退：只有在 `tray_by_id` 能找到托盘时才隐藏窗口，否则保持原来的退出行为。这样即使托盘图标创建失败（例如 shell 异常），应用也不会变成一个既没有窗口也找不回来的后台进程。
- 托盘菜单是原生窗口文字，无法读取前端 i18n 资源，因此新增 `set_tray_language` 命令：前端在语言变化时告知当前界面语言，后端据此重建菜单。标签在 `lib.rs` 中以英文 / 简体中文 / 韩文三套静态表存在。
- 托盘初始使用英文标签。前端加载完成后立即同步为实际界面语言，因此语言切换无需重启。

## 最终行为

点击窗口关闭按钮后窗口隐藏、任务栏按钮消失，应用继续在通知区域运行，计划任务更新与设备同步不受影响。右键托盘图标可显示菜单以恢复窗口或退出应用，左键单击图标直接恢复窗口。托盘菜单文字与界面语言保持一致。
