# Skills Hub v0.10.2

v0.10.2 修复 Windows 上自动更新期间弹出可见且无法操作的窗口的问题，并新增通知区域（托盘）图标：点击窗口关闭按钮改为隐藏到托盘，而不是直接退出应用。

## 修复内容

- 计划任务与手动触发的自动更新不再创建任何窗口，后台运行完全无界面。
- 「立即更新」改为在当前应用进程内执行，不再要求操作系统计划任务拉起第二个应用实例。
- 「立即更新」不再无条件重新注册操作系统计划任务，避免关闭自动更新后任务仍被重建。
- SQLite 连接增加 5 秒写入等待，应用与后台更新共享数据库时不再立即失败。

## 新增内容

- 通知区域图标，菜单提供「显示主窗口」与「退出 Skills Hub」，左键单击图标恢复窗口。
- 关闭窗口改为隐藏到托盘，计划任务更新与设备同步可继续运行。
- 托盘菜单文字跟随界面语言（英文 / 简体中文 / 韩文）。

## 验证

- Windows 实测对照：修复前的二进制在 `--background-task update-skills --force` 下会出现一个 1195×797 的可见 `Skills Hub` 窗口；修复后同一命令行下用户可见窗口数为 0，进程退出码为 0。
- 关闭行为实测：正常启动后发送 `WM_CLOSE`，窗口隐藏且进程继续存活；进程存活本身即证明托盘图标创建成功，因为关闭处理只在托盘存在时隐藏。
- 完整门禁：`npm run lint`、前端测试、`npm run build`、`cargo fmt --all -- --check`、`cargo clippy --all-targets --all-features -- -D warnings` 全部通过。
